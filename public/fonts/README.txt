NEUE MONIGUE FONT
=================
Put your font files here, named exactly:

  NeueMonigue-Regular.woff2   (preferred)
  NeueMonigue-Regular.otf     (or this one)
  NeueMonigue-Regular.ttf     (or this one)

The site picks them up automatically (see src/app/globals.css).
Until the files are added, "Archivo Black" (Google Fonts) is used as a look-alike fallback.
Check that the font's license allows web use.
